license-endpoint.txt.example ... কপি করে license-endpoint.txt বানান

ধাপ ১ — একবার
--------------
    cd LICENSE-SERVER && npm i -g wrangler && wrangler login
    wrangler kv namespace create LIC_KV        → id টা wrangler.toml-এ বসান
    wrangler secret put LICENSE_SECRET         (র‍্যান্ডম, গোপন — কোথাও শেয়ার নয়)
    wrangler secret put TOKEN_SECRET           (লিখে রাখুন, বিল্ডে লাগবে)
    wrangler secret put OWNER_PASSWORD         (কনসোলের পাসওয়ার্ড, ৮+ অক্ষর)
    wrangler deploy                            → https://gtc-license.xxx.workers.dev

ধাপ ২ — বিল্ড
-------------
    cd ..            (GTC ফোল্ডারে ফিরে)
    cp license-endpoint.txt.example license-endpoint.txt
    notepad license-endpoint.txt    # ১ম লাইন Worker URL, ২য় লাইন TOKEN_SECRET
    npm i            (terser + javascript-obfuscator, শুধু প্রথমবার)
    node build.mjs --obfuscate --out github-upload/index.html

ধাপ ৩ — GitHub
--------------
    github-upload/ ফোল্ডারের ৫টা ফাইল → নতুন রিপোতে Upload files
    Settings → Pages → Branch main, folder / (root) → Save
    লিংক: https://আপনারইউজারনেম.github.io/রিপোনাম/

ধাপ ৪ — প্রথম কি
----------------
    লিংক খুলুন → HS লোগোয় ৫ ট্যাপ → OWNER_PASSWORD → 🔑 Keys
    → বায়ারের Gmail + প্ল্যান → Issue on server → activation line কপি → বায়ারকে দিন

টেস্ট চালাতে (ঐচ্ছিক)
---------------------
    node LICENSE-SERVER/test/licensing.test.mjs      # ১৪টা
    (টার্মিনাল ১) node LICENSE-SERVER/dev-server.mjs
    (টার্মিনাল ২) node build.mjs --endpoint http://127.0.0.1:8787 --token dev-token --allow-local --out dist/_dev/index.html
    node e2e.mjs                                    # ২৭টা
